## Project Overview

BMP (Bitmap) test pattern generator for display/panel testing. Generates various test patterns (solid color, grayscale gradient, checkerboard, stripes, color bands, etc.) as BMP images. Originally authored by "ChipWealth / TM-ZD". Python 3.5, PyQt5 GUI.

## Commands

```bash
# Install dependencies
pip install PyQt5 Pillow numpy

# Run CLI version (reads config/cfg.ini, outputs to bmp_out/)
python gen_bmp.py

# Run GUI version
python generate_bmp.py

# Build Windows executable via PyInstaller
pyinstaller -F generate_bmp.py
pyinstaller -F gen_bmp.py
```

## Project Structure

- `gen_bmp.py` — CLI BMP generator. `gen_bmp` class reads `config/cfg.ini` and generates 8 test pattern types (solid color, grayscale gradient, center square, checkerboard, stripes, border frame, color bands, radial spray).
- `generate_bmp.py` — PyQt5 GUI application. `my_main_UI(QMainWindow)` class wraps the same generation logic in a tabbed UI with 11 tabs (8 patterns + grayscale color band, piano keys, BMP-to-text converter). Runs generation via `gen_bmp_thread(QThread)`.
- `gen_bmp_ui.py` — Auto-generated by `pyuic5` from `gen_bmp_ui.ui` (Qt Designer XML). Contains `Ui_MainWindow` with full widget tree.
- `config/cfg.ini` — Configuration file for CLI mode. Section per pattern type with `gen_en` (enable), dimensions, and color parameters.
- `bmp_out/` — Output directory for generated BMP files.

## Architecture

Both CLI and GUI feed parameters into the same `para_input` dict structure, then use **PIL.Image + numpy** to generate BMP pixel arrays:

```
config/cfg.ini ──> gen_bmp.py (gen_bmp class) ──> para_input dict ──> PIL.Image + numpy ──> bmp_out/*.bmp
GUI sliders ──> generate_bmp.py (my_main_UI) ──> para_input dict ──> PIL.Image + numpy ──> bmp_out/*.bmp
```

The GUI's Tab 11 ("其它") also includes a BMP-to-text converter for embedded display driver formats (SPI332, RGB888, SPI111, Gray256).
